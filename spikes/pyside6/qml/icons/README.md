# Sidebar icons

These icons are adapted from the Lucide line icon set and bundled locally so
the desktop app does not depend on an external network request at runtime.

- Source collection: https://www.svgrepo.com/collection/lucide-line-icons/
- Upstream project: https://github.com/lucide-icons/lucide
- License: ISC, as published by Lucide.

The SVGs use a white stroke so the QML button can control inactive-state
contrast through opacity while keeping the icon geometry consistent.
