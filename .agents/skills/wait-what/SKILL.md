# Explain the current Clarify decision

Start with the concrete result or decision. Add the context that was missing, use the project glossary, and give one relevant example if it helps.

Use ASD-STE100 Simplified Technical English. When the user writes Portuguese, use simple controlled Portuguese with the same technical precision. Preserve the intended content and avoid unnecessary jargon.

Answer the clarification, then resume the active task unless the user asked to stop. An explanation request does not reset the original objective.
