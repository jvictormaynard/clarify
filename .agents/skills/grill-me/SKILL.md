# Stress-test a Clarify idea

Read the sibling `grilling` skill. Use the current project and known constraints to examine the request. For durable terminology or architecture decisions, also use `domain-modeling`.

Prefer a small set of decision questions backed by repository evidence. Preserve already settled decisions and the user's stated outcome. Stop the interview when material uncertainty is resolved and continue the authorized work. Do not expand this repository into a personal planning or teaching workspace.
